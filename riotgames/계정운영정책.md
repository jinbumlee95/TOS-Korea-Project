# 계정운영 정책

시행일 : 2020년 8월 2일

라이엇 게임즈 계정 운영정책

### 제1조. 일반 원칙

① 라이엇 게임즈 계정이란, 라이엇 게임즈코리아유한회사 (이하 ‘회사’)에서 제공하는 모든 게임 및 서비스를 하나의 계정으로 이용할 수 있는 통합 계정(이하 ‘계정’)을 의미합니다.

② 계정의 운영정책은 라이엇 게임즈 서비스 약관 (이하 ‘서비스 약관’)을 바탕으로 작성되었으며, 회사에서 제공하는 모든 게임과 서비스를 안정적이고 원활하게 제공하기 위해 마련되었습니다. 계정 운영정책과 서비스 약관 사이에 상반된 내용은 서비스 약관을 우선하여 적용합니다.

③ 계정의 운영정책은 회사의 사정이나 더욱 원활한 서비스 제공을 위해 변경될 수 있으며, 회사는 내용을 변경하는 경우 7일전 (플레이어에게 불리한 항목이 포함된 경우 30일전) 홈페이지를 통해 고지하거나 회원가입 시 입력한 이메일 주소 등을 통해 플레이어 여러분께 고지합니다.

### 제2조. 계정 이용 제한 정책

① 회사는 계정이 타인에게 도용 당했다고 의심되거나 관련 신고가 접수되는 경우 해당 계정을 보호하기 위해 임시로 계정에 접속이 불가능 하도록 조치할 수 있습니다.

② 회사는 계정이 게임 내/외적으로 금전적 거래가 이루어지거나 혹은 거래 의도가 확인되는 경우 계정을 이용할 수 없도록 조치할 수 있습니다.

③ 회사는 게임 내 불건전 행위로 서비스 약관 및 운영정책 등 회사의 정책을 위반하는 경우 서비스 이용을 제한할 수 있습니다. 또한 그 위반 정도가 매우 심각하거나 이용제한이 지속적으로 반복되는 경우 해당 계정의 이용을 영구적으로 제한하거나 해당 플레이어의 명의로 생성된 모든 계정의 이용을 영구적으로 제한할 수 있으며, 추가적인 회원가입을 제한할 수 있습니다. 발생할 수 있는 이용 제한의 종류는 아래와 같습니다.

해당 계정의 채팅(음성 채팅) 이용 제한 (게임 수 / 기간)

해당 계정의 해당 게임 이용 제한 (기간)

해당 계정의 해당 게임 이용 제한 (영구)

동일 명의 모든 계정의 해당 게임 이용 제한 (영구)

동일 명의 모든 계정의 모든 게임 이용 제한 (영구) / 회원가입 제한

### 제3조. 계정 이용 제한 기준

① 계정 보호 조치: 계정이 타인에게 도용됨으로 인해 발생될 수 있는 피해로부터 계정을 보호하기 위해 임시로 계정 접속을 제한하는 조치입니다. 계정 보호 조치가 이루어진 계정은 일부 게임에 접속할 수 없으며, 휴대전화 등을 통해 본인인증 절차를 진행해야만 정상적인 이용이 가능합니다.

② 계정 이용 제한: 게임을 포함해 회사의 서비스 일부 또는 전체를 한시적, 영구적으로 이용할 수 없도록 제한하는 조치 입니다. 불건전 행위의 종류나 정도에 따라 특정 계정에만 적용되거나 동일 명의의 모든 계정에 적용될 수 있습니다.

| 항목 | 조치내용 |

| 계정 도용 및 의심 | 해당 계정 보호 조치 |

| 불건전 행위 | 해당 계정의 채팅(음성 채팅) 이용 제한 (게임 수 / 기간) |

| 해당 계정의 해당 게임 이용 제한 (기간) |

| 해당 계정의 해당 게임 이용 제한 (영구) |

| 동일 명의 모든 계정의 해당 게임 이용 제한 (영구) |

| 동일 명의 모든 계정의 모든 게임 이용 제한 (영구) / 회원가입 제한 |

※ 불건전 행위의 종류 및 세부 제재 기준은 각 게임의 운영정책에 따릅니다.

※ 테스트 기간의 게임 또한 본 정책을 준용하여 적용됩니다.
