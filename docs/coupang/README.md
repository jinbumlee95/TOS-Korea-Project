## 정기 갱신 중단

**쿠팡 약관은 정기적으로 갱신하지 않습니다.** 이 폴더의 최신 커밋은 마지막 수집(2026-09-28) 시점의 버전이며, 그 뒤의 개정은 반영되어 있지 않을 수 있습니다. 현재 약관은 [쿠팡 공식 약관 페이지](https://www.coupang.com/np/policies/terms)에서 확인하세요.

**근거:** 2026-10-02 쿠팡 웹페이지 문의 및 유선으로 약관 데이터 수집 가능 여부를 문의했고, 다음과 같이 회신을 받았습니다.

- **자동화된 수집:** 약관에 의해 불가능합니다. 쿠팡 이용 약관 제12조 제2항 제4호는 회사의 사전 승인 또는 협의 없이 로봇, 스파이더, 스크레이퍼 등 자동화된 수단으로 사이버몰에 액세스하는 행위를 금지합니다.
- **API 등 데이터 제공:** 쿠팡은 API 등을 통해 이용약관 데이터를 제공하지 않습니다.
- **개인에 의한 수집·활용:** 별다른 사항이 없다는 회신을 받았습니다.

회신 원문(웹페이지 문의 답변). 유선 통화 기록 화면과 함께 [문의·회신 근거](evidence/2026-10-02-collection-inquiry/README.md)에 보존합니다.
