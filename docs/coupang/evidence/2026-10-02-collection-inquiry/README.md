# 쿠팡 약관 데이터 수집 가능 여부 문의와 회신

2026-10-02 쿠팡에 약관 데이터 수집 가능 여부를 문의하고 받은 회신을 보존합니다. 이 회신에 따라 쿠팡 약관은 정기적으로 갱신하지 않습니다([쿠팡 설명](../../README.md#정기-갱신-중단)).

## 문의와 회신

- 문의일: 2026-10-02 (한국 시간)
- 문의 경로: 쿠팡 웹페이지 문의
- 회신 경로: 웹페이지 문의 답변, 유선 통화

### 웹페이지 문의 답변 (원문)

> 쿠팡은 API 등을 통해 쿠팡 이용약관 데이터를 제공하지 않으며, 자동화된 접근은 쿠팡 이용 약관 제12조 제2항 제4호에서 금지하고 있는 점 안내 드립니다.
>
> 원하시는 답변드리지 못하여 죄송합니다.

### 유선 회신 (요지)

- 자동화된 수집은 약관에 의해 불가능합니다.
- 개인에 의한 수집·활용에 관해서는 별다른 사항이 없습니다.

통화 내용은 녹음되지 않았으며, 위 요지는 관리자가 통화 뒤 정리한 것입니다. 통화가 있었다는 사실은 아래 통화 기록 화면으로 확인할 수 있습니다.

> 4. 회사가 제공하는 서비스 이용방법에 의하지 아니하고 비정상적인 방법(회사의 사전 승인 또는 협의 없이 로봇, 스파이더, 스크레이퍼 또는 기타 자동화된 수단을 이용하여 회사의 사이버몰에 액세스하는 것을 포함하나 이에 한정되지는 아니함)으로 서비스를 이용하거나 회사의 정보처리시스템에 접근하는 행위
