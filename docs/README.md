## 근거 보존 방식

- 회사 설명은 `docs/{회사}/README.md`에, 게임별 설명은 `docs/{게임사}/{게임}.md`에 둡니다.
- 근거는 `docs/{회사}/evidence/{사례}/`에 원문 파일, 출처·관찰 기록, `SHA256SUMS.txt`를 함께 둡니다.
- 원문 백업은 제공받거나 수집한 파일 그대로 보존합니다. 설명과 분석은 별도 문서에 적습니다.
- 약관의 버전일, 실제 수집 시점, 근거 등록일을 구분합니다. 확인되지 않은 시각은 추정하여 적지 않습니다.
- 관찰된 현상과 사업자가 확인한 오류를 구분합니다. 원인이나 제보·회신이 확인되지 않으면 그 상태를 명시합니다.
- 후속 자료는 별도 파일로 추가하고 확인 날짜와 변경 내용을 기록합니다. 원문과 보존 자료의 권리는 각 권리자에게 있습니다.

[관찰 및 제보 현황](ISSUES.md)에서 사례별 진행 상태를 확인할 수 있습니다.
