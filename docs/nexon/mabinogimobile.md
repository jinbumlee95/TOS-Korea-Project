**넥슨 약관은 정기적으로 갱신하지 않습니다.** 이 폴더의 최신 커밋은 마지막 수집(2026-09-28) 시점의 버전이며, 그 뒤의 개정은 반영되어 있지 않을 수 있습니다. 현재 약관은 위 표의 출처(넥슨 공식 페이지)에서 확인하세요.

**근거:** 넥슨 고객센터 1:1 문의로 약관 데이터 수집·활용 가능 여부를 문의했고, 2026-10-08 다음과 같이 회신을 받았습니다. 회신 원문은 [문의·회신 근거](evidence/2026-10-08-collection-inquiry/README.md)에 보존합니다.

- **자동화된 수집:** 크롤링이나 스크립트 등 자동화된 수단을 통한 수집·접근은 허용 범위가 아닙니다.
- **직접 열람·저장:** 웹브라우저로 직접 열람하고 개인적으로 저장·보존해 변경 이력을 확인하는 것은 제한이 없습니다.
- **변경 이력 활용:** 수동으로 수집한 자료의 시행일, 출처 URL, 조항별 변경 내용은 사전 허가 없이 이용할 수 있고, 원문에 대해서도 저작권을 이유로 한 사전 허가는 필요하지 않습니다. 다만 원문 전체 게시보다 변경 이력 중심 제공을 권장했습니다.
- **외부 공개 시 표시·고지:** 공식 약관 페이지 URL과 시행일 표기, 비공식·비승인 안내, 정확성·최신성 비보증 안내, 원문 임의 수정·편집과 넥슨 로고·상표 사용 금지, 자체 비교·요약과 원문의 구분을 요청했습니다.

- 각 약관 파일 머리말에 `출처`(공식 페이지 URL)와 `시행일자`를 적습니다.
