# 넥슨 약관 데이터 수집 가능 여부 문의와 회신

넥슨 고객센터에 약관 데이터 수집·활용 가능 여부를 문의하고 2026-10-08에 받은 회신을 보존합니다. 이 회신에 따라 넥슨 약관은 정기적으로 갱신하지 않으며, 회신이 요청한 표시·고지 사항을 넥슨 수록 문서에 적용합니다([넥슨 마비노기 모바일 설명](../../mabinogimobile.md#정기-갱신-중단과-표시고지)).

## 문의와 회신

- 문의일: 기록 없음 (2026-10-08 이전)
- 회신일: 2026-10-08 (한국 시간)
- 문의·회신 경로: 넥슨 고객센터 1:1 문의

### 회신 (원문)

> 안녕하세요, 넥슨 고객센터입니다.
>
> 문의해 주신 내용 확인 후 답변드립니다.
>
> 공개된 넥슨 이용약관을 웹브라우저를 통해 직접 열람하고,
> 개인적으로 저장·보존하여 과거 약관 및 변경 이력을 확인하는 것에는 별도 제한이 없습니다.
>
> 다만 본 안내는 이용자가 직접 열람·저장하는 경우에 대한 것으로,
> 크롤링이나 스크립트 등 자동화된 수단을 통한 수집 또는 접근까지 허용하는 의미는 아닌 점 참고 부탁드립니다.
>
> 수동으로 수집한 자료를 변경 이력 확인 목적으로 활용하는 경우,
> 시행일, 출처 URL, 조항별 변경 내용 등의 정보는 별도 사전 허가 없이 이용하실 수 있습니다.
>
> 또한 문의주신 이용약관 원문 자체에 대해서는 저작권을 이유로 별도의 사전 허가가 필요하지 않습니다.
>
> 다만 과거 약관이 현재 적용 중인 공식 약관으로 오인되지 않도록,
> 원문 전체 게시보다는 시행일, 출처 URL, 변경 내용 등 변경 이력 중심으로 제공해 주실 것을 권장드립니다.
>
> ■ 외부 공개 시에는 아래 표시·고지 사항과 이용 시 준수사항을 지켜 주시기 바랍니다.
>
> ●넥슨 공식 약관 페이지 URL 및 해당 약관의 시행일 표기
>
> ●비공식 자료이며 넥슨이 승인하거나 협력하는 프로젝트가 아니라는 점 안내
>
> ●넥슨은 외부 자료의 정확성 또는 최신성을 보증하지 않으며,
> 적용되는 약관은 넥슨 공식 페이지에 게시된 해당 시점의 약관을 기준으로 확인해야 한다는 점 안내
>
> ●약관 원문의 임의 수정·편집 및 넥슨 로고·상표 사용 금지
>
> ●자체 작성한 비교·요약 내용은 원문과 구분하여 표시
>
> 아울러 본 답변은 공개된 이용약관의 열람·저장 및 변경 이력 확인 목적의 활용 범위에 대한 일반적인 안내이며,
> 특정 프로젝트에 대한 넥슨의 공식 승인 또는 협력을 의미하지 않는 점 참고 부탁드립니다.
>
> 감사합니다.

## 회신 요지

| 항목 | 회신 내용 |
|---|---|
| 직접 열람·저장 | 별도 제한 없음 |
| 자동화된 수집·접근 | 허용하는 의미가 아님 (크롤링, 스크립트 등) |
| 수동 수집 자료의 변경 이력 활용 | 시행일, 출처 URL, 조항별 변경 내용은 사전 허가 없이 이용 가능 |
| 원문 저작권 | 저작권을 이유로 한 사전 허가 불필요 |
| 원문 전체 게시 | 금지는 아니나 변경 이력 중심 제공을 **권장** |
| 외부 공개 시 | 아래 표시·고지 사항 준수 요청 |

## 표시·고지 사항 적용

| 넥슨 요청 | 이 저장소의 적용 |
|---|---|
| 공식 약관 페이지 URL과 시행일 표기 | 각 파일 머리말의 `출처`, `시행일자`와 [설명 문서](../../mabinogimobile.md) 표 |
| 비공식 자료, 넥슨 승인·협력 프로젝트 아님 | 설명 문서와 저장소 README에 고지 |
| 정확성·최신성 비보증, 공식 페이지 기준 확인 | 설명 문서와 저장소 README에 고지 |
| 원문 임의 수정·편집, 로고·상표 사용 금지 | 본문 문구는 임의로 수정·편집하지 않고 형식만 Markdown으로 옮기는 것을 원칙으로 함(변환 중 달라진 부분이 발견되면 정정). 넥슨 로고·상표 이미지는 사용하지 않음 |
| 자체 비교·요약은 원문과 구분 | 약관 파일(`nexon/`)에는 원문만 두고, 설명·요약은 `docs/`에만 작성 |

## 원문 전체를 유지하는 이유

넥슨은 원문 전체 게시보다 변경 이력 중심 제공을 권장했습니다(금지는 아님). 이 저장소는 다음 이유로 넥슨 약관 원문을 그대로 유지합니다.

- **비교에는 전문이 필요합니다.** 변경을 찾으려면 비교할 두 버전이 모두 온전히 있어야 합니다. 요약이나 발췌만 남기면 무엇이 빠졌는지, 어떤 문구가 조용히 바뀌었는지 확인할 수 없습니다([저장소 README 2절](../../../../README.md#2-이-프로젝트가-있는-이유)).
- **오인 방지는 표시·고지로 합니다.** 넥슨이 권장한 취지는 과거 약관이 현재 적용 중인 약관으로 오인되지 않게 하는 것입니다. 이를 위해 각 파일 머리말에 `출처`·`시행일자`·`수집일자`를 적고, 위의 표시·고지 사항을 적용했습니다.

다만 넥슨 수록본 4건은 모두 현행본 1판뿐입니다. 약관 변경은 별도 공지사항으로 안내되고, 정책 페이지 안에서는 과거 이력을 제공하지 않기 때문입니다. 그래서 현재는 비교할 이전 버전이 없고, 원문 전체가 게시된 상태입니다. 정기 갱신을 하지 않으므로 앞으로 버전이 쌓일지도 정해져 있지 않습니다.
