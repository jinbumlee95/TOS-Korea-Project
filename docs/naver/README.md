- **과거 버전:** 각 페이지의 "이전 ○○ 보기" 링크를 끝까지 따라가 모았습니다.
- **버전일자:** 다음 순서로 정했습니다.
  1. 새 버전 페이지의 "이전 보기" 링크에 적힌 적용 시작일
  2. 페이지의 시행일자
  3. 그 버전이 대체한 이전 페이지 이름의 교체일
  4. 본문의 "…부터 적용" 문구
- **수록하지 않은 것:**
  - 개인정보 처리방침의 가장 오래된 두 버전(Ver.1.7, 1.8): 날짜 단서가 없습니다.
  - 이메일주소 무단수집 거부: 본문 없이 공지사항으로 넘어가는 페이지입니다.
  - 정보보호 인증·SOC 인증: 약관이 아닙니다.
- **날짜 없는 문서:** 청소년보호정책·법적고지·검색결과 수집 정책은 수집일자로 커밋했습니다.
- **네이버 클라우드 플랫폼:** 네이버 클라우드 플랫폼 약관은 [`navercloud/`](../../navercloud/) ([설명](../navercloud/README.md))에 따로 있습니다.
