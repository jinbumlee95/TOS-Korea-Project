# 토스 서비스 이용약관 과거본의 HTML 표시 상태

서비스 이용약관 2017-04-01 판에서 본문 일부가 HTML 태그를 포함한 코드 블록으로 제공된 상태를 보존합니다. 첨부받은 HTML 자체에 이 구조가 들어 있어, 수록 과정에서만 생긴 표시라고 볼 근거는 없습니다. 사이트의 작성·게시 경위와 오류 여부에 대한 사업자 확인은 아직 기록되어 있지 않습니다.

## 출처와 보존 시점

- 대상 페이지: https://toss.im/docs/11027/11577
- 대상 판: 2017-04-01. 저장된 HTML의 버전 선택 표시와 부칙 시행일에서 확인됩니다.
- 근거 등록일: 2026-10-01 (한국 시간). 원래 페이지를 저장한 정확한 시각은 확인되지 않았습니다.
- 제공 자료: 사용자가 전달한 `11577.htm`과 같은 위치의 `11577_files/` 부속 파일 5개.
- [HTML 보존본](11577.htm), [파일별 SHA-256](SHA256SUMS.txt). 제공 파일을 바이트 단위로 동일하게 복사했습니다.
- 수록본: `toss/서비스이용약관.md`, 커밋 `e2c1a150aae8f68e69582f0437d9be7bebc0684a`. [당시 수록본](https://github.com/jinbumlee95/TOS-Korea-Project/blob/e2c1a150aae8f68e69582f0437d9be7bebc0684a/toss/서비스이용약관.md)

## 확인한 표시 구조

HTML 778, 962, 1057, 1096행에 `<pre><code>`가 있고, 내부 태그가 `&lt;ul&gt;`, `&lt;li&gt;` 등으로 이스케이프되어 있습니다. 해당 블록은 각각 959, 1052, 1093, 1120행에서 끝납니다. 이 구조는 HTML 태그를 목록·제목으로 해석하지 않고 글자로 표시합니다.

기존 수록 기록에 따라 이 부분은 화면에 보이는 코드 블록 형태로 수록했습니다. 이 근거는 제공된 저장본의 상태를 설명하며, 2017년 당시의 화면이나 현재 실시간 사이트 상태를 입증하는 자료로 확대 해석하지 않습니다. 화면 캡처는 포함되어 있지 않습니다.

## 후속 기록

사업자 확인이나 원문 변경이 있으면 확인 날짜·출처·변경 내용을 이 문서에 추가합니다. 새로운 원문은 별도 파일로 보관하여 이번 보존본과 비교할 수 있게 합니다. 사업자 제보·회신은 현재 미기록 상태입니다.
