# 약관 데이터 오류 제보 기록

TOS-Korea는 약관을 상업적으로 재이용하려는 목적이 아니라, 공개 약관의 변경 이력을 연구·기록하고, 그 검증 과정에서 발견되는 오류를 사업자에게 전달하는 프로젝트입니다.

이 문서는 수집·비교 중에 발견해 사업자에게 제보한 오류와 그 처리 결과를 사실관계 중심으로 기록합니다.

- 한 줄이 제보 한 건입니다. 새 제보는 아래에 추가합니다.
- 기업 답변은 받은 내용을 요약해 적습니다. 회신 전문이 필요한 경우 회사별 설명 문서(`docs/{회사}.md`)에 적습니다.
- 결과는 사업자 쪽 조치가 반영되면 갱신합니다.
