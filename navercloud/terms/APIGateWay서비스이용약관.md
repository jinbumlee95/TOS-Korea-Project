# API GateWay 서비스 이용약관

네이버 클라우드 플랫폼 API Gateway 서비스 이용약관

### 제 1 조 (목적)

본 약관은 네이버클라우드 주식회사(이하 ‘회사’라 합니다)가 제공하는 네이버 클라우드 플랫폼 서비스 중 API Gateway 서비스(이하 ‘본 서비스’라 합니다)를 이용함에 있어 회사와 본 서비스를 이용하고자 하는 고객(네이버 클라우드 플랫폼 서비스 이용약관에 동의한 회원으로써 본 서비스를 추가적으로 이용하고자 하는 자를 의미합니다, 이하 ‘고객’이라 합니다) 간의 권리와 의무 및 기타 필요한 사항을 규정하는데 그 목적이 있습니다.

### 제 2 조 (용어의 정의)

본 약관에서 사용하는 용어의 정의는 다음과 같습니다. ① 본 약관에서의 "API(Application Programming Interface)”란 각종 응용 프로그램들 간의 통신에 사용되는(통신을 위해제공되는) 언어나 메시지 형식 등의 인터페이스를 의미합니다. ② 본 약관에서의 “API Gateway Platform” 또는 “AGP”란 고객이 자신이 직접 개발하는 등 AGP 에 그 이용조건을 정하여 제공할권리를 확보한 API 를 AGP 에 그와 같이 이용조건을 설정하여 제공하여 자신 또는 다른 고객이 AGP 를 통해 해당 API 를 이용할 수 있도록 하고 그와 관련된 지원을 하는 플랫폼을 의미하며, 이와 같은 플랫폼을 관련되는 부가서비스(기술지원 등)와 함께 제공하는 서비스를 “API Gateway 서비스” 또는 “본 서비스”(제 1 조 참조)라 합니다. ③ 본 약관에서의 “등록”이란 고객이 자신이 직접 개발하는 등 AGP 에 그 이용조건을 정하여 제공할 권리를 확보한 API 를 AGP 에 이용조건을 설정하여 제공하는 것을 의미합니다. ④ 본 약관에서의 “이용”이란 고객이 AGP 에 등록되어 있는 API 를 그 이용조건을 준수하여 사용하는 것을 의미합니다. ⑤ 본 약관에서의 “API 제공자”란 API 를 등록하여 자신 또는 다른 고객이 해당 API 를 이용할 수 있도록 하는 자를 의미하며, “API 이용자”란 등록된 API 를 이용하는 자를 의미합니다. ⑥ 본 약관에서의 “API 인증키”란 본 서비스의 운영자로부터 API 제공자에게 등록하는 개별 API 별로 부여되는 알파벳 및 아라비아 숫자로 조합된 고유값을 의미합니다. ⑦ 본 약관에서 별도로 정의하지 않은 용어는 네이버 클라우드 플랫폼 서비스 이용약관에서 정한 바에 따릅니다.

### 제 3 조 (API Gateway 서비스 이용 계약의 체결 및 효력)

① 본 서비스에 대한 이용계약은 고객이 본 약관에 동의하고 이용신청을 한 후, 회사가 이에 대해 승낙함으로써 성립합니다. ② 본 약관에서 정하지 않은 사항은 네이버 클라우드 플랫폼 서비스 이용약관, 관계법령, 상관례 및 홈페이지에 명시된 서비스 별설명 내용이 적용됩니다.

### 제 4 조 (본 서비스의 제공)

① 회사는 AGP 등 API Gateway 서비스(본 서비스)를 제공합니다. API Gateway 서비스(본 서비스)의 구체적인 모습은 서비스 홈페이지에 게시됩니다.

② 고객은 본 약관에 따라 API 제공자로서 AGP 에 자신이 직접 개발하는 등 AGP 에 그 이용조건을 정하여 등록할 수 있습니다. ③ 고객은 본 약관에 따라 API 이용자로서 AGP 에 등록된 API 를 그 이용조건을 준수하여 이용할 수 있습니다.

### 제 5 조 (준수사항 및 보증)

① 고객은 본 서비스를 이용함에 있어서 본 약관 및 네이버 클라우드 플랫폼 서비스 이용약관, 관계 법령 및 홈페이지에 게시되는 준수사항 등을 준수하여야 하며, 이를 지키지 않아 발생하는 일체의 문제(정부 기관, 권리자 등으로부터의 소송, 수사 제기 등 일체의 민형사상의 권리침해 및 법 위반 주장 등을 포함합니다)에 대해 자신의 비용과 노력으로 회사를 면책하고, 회사 및 제 3 자 등 그로 인해 손해를 입은 자에 대해 배상해야 합니다. 다만, 회사의 귀책이 있는 부분에 대해서는 그러하지 아니 합니다.

② API 제공자는 자신에게 발급된 API 인증 키를 자신의 책임으로 안전하게 관리하고 API 인증 키와 관련하여 회사가 공지한 모든 사항을 준수하여야 합니다. 또한 만약 발급 받은 API 인증 키의 도용 등이 의심되는 경우에는 즉시 회사에 알리고 해당 API 인증 키는 삭제한 후 새로운 API 인증 키를 발급 받아 자신의 API 에 적용시켜야 합니다. API 제공자가 이와 같은 내용을 준수하지 않아 발생하는 모든 문제에 대해서는 회사는 책임을 지지 않습니다.

③ API 제공자는 API 를 AGP 에 등록함에 있어서 API 자체 또는 API 의 그와 같은 등록 및 등록을 통한 다른 고객의 이용이 관련 법령을 위반하거나 제 3 자(예를 들면, 해당 API 의 저작권자)의 권리(예를 들면 특허권, 상표권, 저작권 등 지식재산권 또는 초상권 등 인격권)를 침해하지 않는다는 것을 보증합니다.

④ API 제공자는 자신이 AGP 에 등록한 API 를 사용하여 발생하는 모든 문제에 대해서 스스로 책임을 질 것임을 보증합니다. 다만, 그와 같은 문제가 본 서비스 자체의 문제로 인한 경우는 그러하지 아니합니다.

⑤ API 이용자는 자신의 API 사용 및 그와 같은 사용을 통해 자신 혹은 제 3 자의 어플리케이션 등을 통해 제공되는 프로그램 및 서비스가 관련 법령을 위반하거나 제 3 자(예를 들면, 해당 API 의 저작권자 혹은 어플리케이션 등의 이용자 등)의 권리(예를 들면 특허권, 상표권, 저작권 등 지식재산권 또는 초상권 등 인격권)를 침해하지 않는다는 것을 보증합니다.

⑥ API 이용자는 API 를 사용하여 발생하는 모든 문제(API 를 이용하는 어플리케이션 등을 이용하는 자와의 문제를 포함합니다)에 대해서 회사가 아닌 API 제공자와 문제를 해결할 것임을 보증합니다. 다만, 그와 같은 문제가 본 서비스 자체의 문제로 인한 경우는 그러하지 아니합니다.

⑦ 회사는 고객이 본 조를 위반한 것을 확인하거나 위반에 대한 신고가 접수될 경우 회사는 제 7 조에 따른 제한조치 및 네이버 클라우드 플랫폼 서비스 이용약관에 의한 조치를 취할 수 있습니다.

⑧ 회사는 고객에게 본 조의 준수 여부를 확인하기 위하여 필요한 정보나 증빙서류 등을 제공할 것을 고객에게 객관적으로 합리적인 수준에서 요청할 수 있으며, 고객은 이에 응하여야 합니다.

### 제 6 조 (권리의 귀속)

① 고객이 등록하는 API 의 저작권 등 관련 권리는 고객 또는 원래의 권리자에게 귀속됩니다. ② 본 서비스와 관련된 모든 권리(지식재산권 등)는 회사에 귀속됩니다.

### 제 7 조 (제한조치)

회사는 다음 각 호의 경우, 해당 고객에 대해서 발급한 인증 키의 회수 또는 사용제한 등 본 서비스의 제공을 중단할 수 있습니다. 1. 고객이 본 서비스를 이용함에 있어서 본 약관, 네이버 클라우드 플랫폼 서비스 이용약관 또는 관련 법령(정보통신망법, 개인정보보호법, 저작권법 등을 포함한다)을 위반한 경우 2. 고객이 본 서비스를 이용함에 있어서 저작권 등 제 3 자의 권리를 침해한 경우 3. 고객이 본 서비스를 이용함에 있어서 건전한 사회질서를 위반하거나 미풍양속, 공공질서에 반하는 행위를 하는 경우 4. 고객이 회사의 시스템, 서버 등에 과부하를 발생시키거나, 자동화 프로그램 등을 통해 기계적인 접근을 하거나, 침입 또는 침입을 시도하는 등 회사의 시스템 및 서버에 부당하게 접근하거나 그러한 시도를 하는 경우 5. 이용자가 회사가 명확히 공지한 운영정책, 공지사항을 위반하는 경우

### 제 8 조 (개인정보 보호)

고객은 본 서비스를 이용하여 어플리케이션 등을 통해 서비스를 자신의 이용자에게 제공함에 있어서 정보통신망법, 개인정보보호법 등 개인정보 관련 법령을 준수하여야 하며, 그와 관련한 문제가 발생할 경우 회사를 자신의 비용과 책임으로 면책하여야 합니다. 다만, 그러한 문제가 회사의 귀책으로 인해 발생한 경우에는 그러하지 아니 합니다.

### 제 9 조 (서비스의 이용요금)

① 본 서비스의 이용 요금의 세부 내역 및 그 변경사항은 회사의 서비스 홈페이지에 게시합니다. ② 본 서비스의 이용요금은 매월 1 일부터 해당월 말일까지 1 개월 단위로 산정됩니다. ③ 회사는 본 서비스에 대한 이용요금을 네이버 클라우드 플랫폼서비스 이용 요금과 함께 청구하며, 고객은 네이버 클라우드플랫폼서비스 이용 요금과 함께 본 서비스 이용요금을 지불해야 합니다.

### 제 10 조 (면책사항)

① 회사는 고객의 귀책 사유로 인한 본 서비스 이용 장애에 대해 책임을 지지 않습니다. ② 회사는 고객 상호간 또는 고객과 제 3 자 상호간 본 서비스를 매개로 발생한 분쟁에 대해 개입할 의무가 없으며, 이로 인한손해에 대해서도 배상할 책임이 없습니다. 단, 그와 같은 분쟁 및 손해가 회사의 귀책으로 인한 경우에는 그러하지 아니 합니다.

부칙 본 약관은 2020 년 10 월 15 일부터 적용됩니다.
