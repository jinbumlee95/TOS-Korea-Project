# Cloud Security Watcher 서비스이용약관

네이버 클라우드 플랫폼 Cloud Security Watcher 서비스 이용약관

### 제 1 조 (목적)

본 약관은 네이버클라우드 주식회사(이하 “회사”)가 제공하는 네이버클라우드플랫폼 서비스 중 Cloud Security Watcher 서비스(이하 ‘본 서비스’)를 이용함에 있어 ‘회사’와 ‘이용고객’(이하 ‘고객’)간의 권리와 의무 및 기타 필요한 사항을 규정하는데 그 목적이 있습니다.

### 제 2 조 (용어 정의)

본 약관에서 사용하는 용어의 정의는 다음과 같습니다. ① “고객”이라 함은 ‘회사’의 서비스에 접속하여 본 약관에 따라 ‘회사’와 이용계약을 체결하고 ‘회사’가 제공하는 서비스를 이용하는개인 또는 법인, 공공기관 등을 의미합니다. ② “Cloud Security Watcher 서비스”라 함은 “네이버 클라우드 플랫폼”에서 보안 프레임워크 준수 현황 점검, 자산 현황 식별, 자산 변경 감시를 지원하는 CSPM(Cloud Security Posture Management) 서비스를 의미합니다. ③ “CSPM”이라 함은 고객의 클라우드 자원의 형상을 관리하여 보안 정책 이상 여부를 판단하는 클라우드 보안 형상 관리서비스를 의미합니다. ④ “시각화”라 함은 자산별 주요 형상 및 위협 상태를 시각화한 대시보드와 세부 View 를 제공하여 자산 상태를 한눈에 파악할 수기능을 의미합니다. ⑤ “컴플라이언스 평가”라 함은 ISMS-P 등 주요 보안 프레임워크를 기준으로 클라우드 상에서 제공하는 서비스의 규정 준수여부를 평가하는 것을 의미합니다.

### 제 3 조 (본 서비스 이용계약의 체결 및 효력)

① '고객'이 본 약관에 동의 및 이용신청을 하고 '회사'가 이를 승낙함으로써 '본 서비스'에 대한 이용계약이 성립합니다. ② 본 약관에 명시하지 않은 사항은 네이버 클라우드 플랫폼 서비스 이용약관, 관계법령, 상관례 및 홈페이지에 명시된 서비스별안내를 적용합니다.

### 제 4 조 (서비스의 제공 등)

① ‘고객’은 Cloud Security Watcher 를 사용함으로써, 고객이 소유한 자산에 대한 자산 정보 확인 및 감시, 컴플라이언스 관리, 계정별 자산 정보 변경 감시 및 변동 이력 관리가 가능합니다.

② ‘고객’은 Cloud Security Watcher 서비스를 이용하는 방식 중 API 방식과 Agent 방식을 결합하여 멀티 클라우드, 온프레미스(On-Premises) 환경, 하이브리드 환경 등에 대한 통합 보안 관리 서비스를 이용할 수 있습니다.

③ “Cloud Security Watcher 서비스”는 (i)고객 자산 현황에 대한 시각화 (visualization), (ii)주요 보안 프레임워크 준수 여부에 대한 평가 (컴플라이언스), (iii)자산에 대한 위험 평가, 모니터링 및 조치를 지원합니다.

### 제 5 조 (권리 및 의무)

① ‘고객’은 Cloud Security Watcher 서비스를 이용함에 있어 ‘고객’의 서버 자산 정보를 수집하기 위해 API 방식과 Agent 방식 중에서 선택합니다. Agent 방식을 사용하는 경우에는 Agent 프로그램 추가 설치가 필요합니다.

② ‘고객’은 Cloud Security Watcher 이용을 위해 Sub Account 에 대한 Access Key ID 와 Secret Key 를 연동해야 합니다. ③ ‘고객’이 설치하는 Agent 는 시스템의 주요 정보를 읽어와 매니저에게 전달하는 역할을 하기 때문에, 시스템 요건상 최고관리자 계정으로 설치해야 합니다. ④ ‘고객’은 고객의 시스템 환경이 Cloud Security Watcher Agent 를 지원하는 서버 사양에 부합하도록 하여야 하며, 그렇지 않을경우 Agent 가 실행되지 않습니다. ⑤ ‘고객’은 Cloud Security Watcher 를 생성한 시점부터 이용 요금이 발생하므로 과금을 원하지 않는 경우 사용자가 직접콘솔에서 서비스 이용 해지 및 서비스 연동 종료 조치(반납 등)를 수행해야 합니다. 미조치 시 이용 요금이 발생할 수 있으며 청구 금액은 환불되지 않습니다. ⑥ ‘고객’이 Cloud Security Watcher를 이용 해지 또는 삭제하거나 고객이 이용약관을 위배하여 회사에 의해 해지되는 경우, 연동 설정된 계정 정보를 비롯한 본 서비스 상 모든 정보가 삭제되며 복구할 수 없습니다. 따라서 고객은 본 서비스 이용 해지 전에 스스로 정보를 백업할 의무가 있습니다.

### 제 6 조 (서비스의 이용요금)

① ‘본 서비스’ 이용 요금의 세부 내역 및 그 변경사항은 회사의 서비스 홈페이지에 게시합니다.

② ‘본 서비스’ 이용계약 기간 중 이용요금이 변경되더라도 현재 이용 중인 ‘본 서비스’ 이용기간에 대해서는 특별한 사정이 없는 한 소급 적용되지 않습니다.

③ ‘본 서비스’의 이용요금은 매월 1 일부터 해당월 말일까지 1 개월 단위로 산정됩니다. ④ ‘회사’는 ‘본 서비스’에 대한 이용요금을 네이버 클라우드 플랫폼 서비스 이용 요금과 함께 청구하며, ‘고객’은 네이버 클라우드플랫폼 서비스 이용 요금과 함께 ‘본 서비스’ 이용요금을 지불해야 합니다.

부칙 본 약관은 2024 년 3 월 21 일부터 적용됩니다.
